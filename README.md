# insomnia_grist
Доработки в базе данных Grist для фестиваля Бессонница

Тут сохраняю python код, который создается в базе Grist, чтобы можно было отслеживать изменения. Перенести этот код в базу не получится, т.к. Grist не дает такой возможности: делать правки можно только в самой базе. Но для того чтобы понять как было и как стало буду использовать историчность git.

Важное замечание: в репозитории только код, без данных, данные только в базе.
